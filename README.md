# harness-engineering

Foundations for how we build harnesses and AI-based software.

- `FOUNDATIONS.md` — first principles, anatomy, decision rules, operating loop, 90-day plan. Revision 5, Codex-accepted 2026-11-07.
- `review/` — five-round Codex adversarial review: prompts and extracted findings per round.

## Sources (not redistributed here)

- **P**: Barbaste et al., *Harness Engineering: Anatomy, Architecture, and Evolution of Coding Agents*, arXiv 2609.00006, July 2026. https://arxiv.org/abs/2609.00006
- **G**: Huashu, *Harness Engineering: The Complete Guide*, v260411, April 2026.

The PDFs, their extracted texts (`review/paper-2609.00006.txt`, `review/guide-v260411.txt`), and the raw Codex transcripts (`review/codex-round*.txt`, which echo the source texts) are kept locally under `sources/` and `review/` and are gitignored.
